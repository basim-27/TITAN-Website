# TITAN – Institute Website

A modern, responsive, multi-page educational institute website built for **TITAN – Taj Institute of Technology & Applied Networks**.

This project combines AI-assisted development with my own coding skills, custom implementations, and design decisions. I used AI tools as development assistance while actively contributing through HTML5, CSS3, Bootstrap 5, and custom styling.

## 🌐 Live Preview

**[Visit TITAN Website](https://titan-website-1.netlify.app/)**

## 📂 GitHub Repository

**[View Source Code](https://github.com/basim-27/TITAN-Website)**

## 📄 Website Pages

- **Home:** Introduction, hero section, featured courses, statistics, and highlights.
- **About Us:** Information about TITAN and its educational vision.
- **Courses:** Course offerings and program details.
- **Campuses:** Campus information and locations.
- **Enrollment:** Detailed student registration form with multiple information sections.

## ✨ Features

- Multi-page website structure.
- Modern and professional UI design.
- Responsive layouts for desktop, tablet, and mobile.
- Bootstrap 5 grid system and components.
- Custom CSS styling and animations.
- Animated SVG illustrations and decorative elements.
- Font Awesome icons.
- Google Fonts integration.
- Interactive navigation and dropdown menus.
- Course cards and campus sections.
- Detailed front-end admission registration form.
- Custom hover effects and transitions.
- Mobile-friendly navigation menu.

## 🎨 Development Approach

This project was developed using a combination of:

- **My Own Coding:** Writing and customizing HTML5 and CSS3 code.
- **AI-Assisted Development:** Using AI tools for development assistance, ideas, and improvements.
- **Custom Implementation:** Adjusting layouts, styling, animations, and individual website sections according to my requirements.

The goal was not just to generate a website, but also to practice my development skills and learn how different technologies work together in a real-world style project.

## 🚀 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/basim-27/TITAN-Website.git
   ```

2. Open the project folder:

   ```bash
   cd TITAN-Website
   ```

3. Open `index.html` in your browser.
